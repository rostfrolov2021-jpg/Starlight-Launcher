Новая иконка Starlight для приложения, ярлыков и установщика. Обновления теперь загружаются с GitHub Releases без локального сервиса.

Включены консоль игрового сервера, OP/deop, панель online-mode и сетевых настроек, ядра Vanilla, Paper, Fabric, Spigot, Forge, Nukkit и гибриды Arclight/Youer, каталоги сборок и исправления регистрации.

Для первой установки Windows x64 скачайте **Starlight-Setup-1.3.0-win-x64.exe**. Уже установленный лаунчер обновляется через «Обновления → Обновить и перезапустить». Перед обновлением закройте Minecraft и остановите игровой сервер. Сборки и миры сохраняются.

Nukkit предназначен для Bedrock. Вход Microsoft требует настройки собственного Application (client) ID. GitHub размещает файлы приложения; публичный сервис друзей/чата на нём не запускается.
