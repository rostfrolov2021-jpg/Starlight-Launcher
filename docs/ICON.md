# Иконка Starlight

Создана встроенным инструментом генерации изображений. Исходник: `src/Starlight.Desktop/Assets/starlight.png`; Windows ICO содержит размеры 16, 20, 24, 32, 40, 48, 64, 128 и 256 px. Одна и та же иконка используется для EXE, ярлыков, окна и установщика.

Промпт: Create a production-ready Windows application icon for Starlight Launcher, a tasteful Minecraft launcher with charcoal and muted sage green UI. Square icon artwork, 1024x1024. A bold elegant four-point ivory/sage north star hovering above a simple angular low mountain ridge, enclosed in a dark charcoal rounded-square badge with restrained bevel and very subtle green illumination. Original distinctive mark, polished handcrafted feel, almost flat with just enough tactile depth, strong geometric silhouette readable at 16 pixels, centrally balanced, generous but not excessive inset. Two large mountain facets only, one dominant star, no tiny decorative stars, no particles. No lettering, no words, no logos of other brands, no mockup, no surrounding scene, no drop shadow outside badge. Transparent outside the rounded square. This exact icon will be used for executable, desktop shortcut, installer and window title bar. Deliver only the icon.
