# Результаты проверки

Проверка выполнена в Windows x64 с локальным .NET SDK 8.0.427.

| Проверка | Результат |
|---|---|
| `dotnet build Starlight.sln --no-restore -c Release -m:1` | 0 ошибок, 0 предупреждений |
| Локальные проверки хранения, загрузок, модов и Opus | 28 успешно, включая стабильный UUID в CmlLib launch session |
| Локальный ASP.NET Core + реальные SignalR-клиенты | 13 дополнительных проверок успешно |
| Совместный прогон локальных и интеграционных проверок | 41 успешно |
| Реальные API Mojang / Modrinth / Fabric | 7 дополнительных проверок успешно |
| Прямой туннель | Проверен маршрут P2P, двоичный echo 200 КБ, работа чата при открытом туннеле |
| Резервный туннель | Проверен маршрут relay при недоступном UDP, двоичный echo 200 КБ, работа чата |
| Запуск Avalonia | Завершился успешно; отрисованы семь страниц |
| Self-contained Windows EXE | Запущен, снимок главной страницы сохранён, приложение закрыто |
| Inno Setup 6.7.4 | Установщик скомпилирован |

Проверки модов включают обновление версии с сохранением отключённого состояния и восстановление предыдущего JAR после ошибки записи.

Скриншоты: `artifacts/starlight-preview.png`, `artifacts/ui-pages/`. В снимках используется отдельный `STARLIGHT_HOME=artifacts/ui-smoke`, а не пользовательское хранилище. Тестовые серверы остановлены после прогона. Тестовые аккаунты и данные находятся только в `artifacts/`.

Не проверялись: Microsoft OAuth с настоящим аккаунтом, CurseForge с ключом, скачивание полного Minecraft и игровой сеанс, реальные микрофоны/аудиоустройства двух компьютеров, WAN между разными провайдерами, установка/деинсталляция готового установщика, запуск на Linux/macOS. Голосовой relay и акустическое эхоподавление не реализованы. Эти ограничения не скрываются за результатами локальных тестов.

Повторение сетевого прогона: `powershell -File scripts/test-integration.ps1`. Скрипт поднимает временный localhost-сервер, запускает проверки и останавливает именно созданный им процесс.
