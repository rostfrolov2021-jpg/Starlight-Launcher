# Публикация Starlight на GitHub

Репозиторий: https://github.com/rostfrolov2021-jpg/Starlight-Launcher

Скачать последнюю версию: https://github.com/rostfrolov2021-jpg/Starlight-Launcher/releases/latest

Постоянный адрес ленты обновлений:
`https://github.com/rostfrolov2021-jpg/Starlight-Launcher/releases/latest/download/latest.json`

## Выпустить следующую версию через GitHub

1. Загрузите изменения исходников в `main`.
2. Измените `<Version>` в `Directory.Build.props`, например с `1.3.0` на `1.3.1`. Версия установщика берётся из этого файла автоматически.
3. Обновите `RELEASE_NOTES.md`: описание изменений и имя нового установщика. Сохраните изменения в `main`.
4. Откройте **Actions → Publish Windows release → Run workflow**, выберите `main` и запустите.
5. Дождитесь зелёного результата. В **Releases** появится новый выпуск с EXE, ZIP, `latest.json` и `SHA256SUMS.txt`. Пользователи увидят его в лаунчере.

Сборка сначала проходит проверки, затем создаёт установщик и подписывает обновление. Выпуск создаётся черновиком, публикуется только после загрузки всех четырёх файлов. Повторная публикация существующей версии запрещена: для исправлений увеличьте версию. При ошибке загрузки остаётся черновик — изучите журнал Actions перед повторной попыткой.

Нельзя просто заменить один EXE в Releases: лаунчер принимает ZIP только с соответствующим SHA-256 и подписанным `latest.json`. Процесс выше делает это автоматически.

## Выпустить с этого компьютера

Нужны PowerShell 7, .NET 8 SDK, Inno Setup 6, Git и GitHub CLI. В текущей рабочей копии инструменты доступны в `.tools`.

```powershell
# Измените Version и RELEASE_NOTES.md, затем сохраните исходники:
git add src tests scripts .github docs README.md RELEASES.md RELEASE_NOTES.md Directory.Build.props installer.iss build.ps1 .gitignore
git commit -m "Prepare release 1.3.1"
git push origin main
pwsh -File scripts/publish-github.ps1
```

Для просмотра перед публикацией добавьте `-Draft`. После загрузки проверьте черновик на GitHub и нажмите **Publish release**. Если уже есть проверенная сборка, используйте `-SkipBuild`.

## Подпись и данные

Закрытый ключ хранится локально в `.tools/release-private.pem` и в зашифрованном GitHub Actions secret `STARLIGHT_RELEASE_PRIVATE_KEY`. Он никогда не добавляется в Git или ZIP. Сделайте отдельную приватную резервную копию: смена ключа без миграции сломает обновления существующих установок. Для новой машины восстановите именно исходный ключ.

В репозитории находится только публичный ключ проверки. Подпись пакета Starlight не является подписью Windows Authenticode: у Windows может отображаться «Неизвестный издатель». Сертификат издателя отдельно не приобретался.

Настройки, аккаунты, миры, токены, тестовые загрузки и каталог `.tools` не публикуются. GitHub хранит исходники и файлы выпусков, но не заменяет работающий сервер друзей/чата или Minecraft-сервер.

## Переход с локальных обновлений

На исходном компьютере обновление 1.3 публикуется также в уже настроенную локальную ленту. Установите его обычной кнопкой лаунчера. После запуска 1.3 старый loopback-адрес ленты автоматически заменится на GitHub. Пользовательские внешние адреса сохраняются. Для новой установки скачайте EXE из Releases.
