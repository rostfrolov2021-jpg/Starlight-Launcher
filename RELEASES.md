# Starlight 1.2 — консоль и управление сервером

## Обновление с 1.1

Переустановка не требуется. Остановите игровой сервер и закройте Minecraft, затем в установленном лаунчере откройте «Обновления → Проверить → Обновить и перезапустить». Подписанный пакет 1.2 сохраняет сборки, миры и аккаунты вне папки приложения. Локальная лента работает, пока запущен сервис Starlight на этом компьютере; публичный адрес для распространения другим пользователям пока не настроен.

* **Серверы → Консоль:** вывод выбранного сервера, ввод команд с Enter, список игроков, сохранение мира, выдача и снятие OP. Сервер нужно запускать кнопкой в лаунчере: к stdin процесса, запущенного отдельно, лаунчер не подключается.
* **Настройки сервера:** online-mode (Xbox authentication у Nukkit), доступ из сети, whitelist, порт, число игроков и описание. Остановите сервер, сохраните изменения и запустите снова. При отключённой проверке аккаунтов ник не подтверждён владельцем — не выдавайте права случайным посетителям.
* **Подключение:** собственный компьютер — `127.0.0.1:порт`; другой компьютер в той же сети — показанный LAN IP и порт. Для интернета включите доступ из сети, разрешите порт в брандмауэре и перенаправьте его на роутере. Java использует TCP (обычно 25565), Nukkit — UDP (обычно 19132). Друзьям передайте публичный IP и порт. При CGNAT потребуется внешний доступ от провайдера или публичный relay/VPN; локальная кнопка сама публичный IP не создаёт.
* **Ядра:** добавлены Spigot (официальный BuildTools), Forge, Nukkit, Arclight и Youer; Fabric, Paper и Vanilla сохранены. Nukkit — Bedrock, не Java. Доступность гибридов зависит от выбранной версии Minecraft, совместимость модов и плагинов не гарантируется.
* **Аккаунт Starlight:** имя — 3–24 латинских символа, цифры или `_`, пароль — 12–256 символов. Ошибки регистрации теперь показывают причину, включая занятое имя. Этот аккаунт служит для друзей/чата и не заменяет лицензию Minecraft.
* **Microsoft:** исправлены подсказки ошибок и сохранение Client ID перед входом. В настройках был указан Microsoft Services Tenant ID вместо Application (client) ID; Microsoft отвергает его с AADSTS700016. Нужна регистрация собственного приложения по инструкции ниже. Пароль Microsoft вводится только на официальной странице.
* На странице «Мои сборки» возвращён фон с горами и луной без надписи; оформление слегка обновлено.

## Проверка 1.2

Проверка выпуска 1.2 на Windows x64: 78 функциональных и интеграционных проверок; реальный запуск Forge и Nukkit с командами и остановкой; официальная сборка Spigot 1.21.1 через BuildTools; скачивание Arclight и Youer с проверкой контрольных сумм. Совместимость произвольных модов/плагинов в гибридах отдельно не проверялась. Подписанная лента и применение обновления проверены на тестовой копии. Установленный Starlight 1.1 обнаружил 1.2; установку оставили пользователю.

## Возможности 1.1, сохранённые в 1.2

Запустите `artifacts/publish/win-x64/Starlight.exe` или установите `artifacts/installer/Starlight-Setup-1.1.0-win-x64.exe`.
Для перехода с 1.0 установщик нужен один раз: у старого выпуска ещё нет обновлятора. Сборки и аккаунты остаются в `%APPDATA%/.starlight`, вне папки программы.

* **Мои сборки → Добавить сборку:** Modrinth, CurseForge, чистая игра, импорт `.mrpack` или CurseForge `.zip`. Выберите проект, нажмите «Версии сборки», выберите выпуск и установите. Для модов по отдельности остаётся страница «Моды».
* **Серверы → Открыть папку сервера:** полный доступ к `plugins`, `world`, настройкам. Папка `plugins` создаётся ядром Paper; Vanilla не загружает плагины. Остановите игровой сервер перед заменой мира.
* **Настройки → Запустить локальный сервис:** скрытый процесс, адрес заполняется и проверяется автоматически. Он работает до закрытия лаунчера. «Остановить сервис» позволяет перезапустить его после изменения ключей.
* **Настройки → Привязать API:** вставьте HTTPS-адрес будущего публичного сервиса. Client ID Microsoft, доступ к прокси CurseForge и адрес обновлений приходят автоматически. Ключ CurseForge остаётся у оператора сервиса.
* **Аккаунты → Получить код входа:** скопируйте код, откройте Microsoft и войдите на официальной странице. Лаунчер ждёт подтверждения; «Отмена» прерывает ожидание. После входа сохраните аккаунты в защищённом хранилище. При следующем запуске разблокируйте его.
* **Обновления:** проверка при старте сообщает о новой версии. «Обновить и перезапустить» скачивает пакет, проверяет подпись и SHA-256, завершает лаунчер и заменяет файлы. Перед этим нужно закрыть Minecraft и остановить игровой сервер.

Публичный сервис пока не создан, Microsoft Client ID и CurseForge API key не предоставлены. Поэтому Modrinth доступен сразу; Microsoft и CurseForge станут доступны после настройки владельцем. Пароль Microsoft не вводится в лаунчер.

## Владельцу: локальная лента

Нужен PowerShell 7 (`pwsh`) для подписи выпусков. Обычная сборка работает и в Windows PowerShell 5.

```powershell
# Собрать программу, сервис, обновлятор и установщик
.\build.bat -Installer
# Создать подписанный ZIP и latest.json для встроенного локального сервиса
pwsh -File scripts/publish-release.ps1 -Version 1.1.0 `
  -BaseUrl http://localhost:5088 -Output "$env:APPDATA/.starlight/releases" `
  -Notes "Каталоги сборок, обновления и новый интерфейс"
```

Затем в лаунчере запустите локальный сервис и откройте «Обновления → Проверить». Для 1.1.0 появится сообщение об актуальной версии. Следующий выпуск требует увеличения `<Version>` в `Directory.Build.props`, версии в `installer.iss`, новой сборки и запуска публикации с новым `-Version`. Скрипт проверяет совпадение версии пакета с программой и не перезаписывает опубликованные ZIP.

Подпись RSA-PSS проверяется встроенным публичным ключом. **Сохраните резервную копию `.tools/release-private.pem` в закрытом месте.** Не включайте его в установщик, публичный репозиторий или каталог releases. Замена этого ключа без миграции сломает обновления уже установленных клиентов. Цифровая подпись пакетов не является Windows Authenticode-подписью EXE.

При неудачной замене файлов обновлятор возвращает старые файлы. Диагностика и резервные копии: `%APPDATA%/.starlight/cache/updates/<версия-id>/updater.log` и `backup/`. После ошибки программу можно открыть обычным ярлыком. Старые файлы, отсутствующие в новом пакете, автоматически не удаляются.

## Владельцу: публичный сервис

Запустите `artifacts/server/win-x64/Starlight.Server.exe` на выбранном хосте; либо используйте `deploy/compose.yaml`. Переменные окружения:

| Переменная | Значение |
|---|---|
| `ASPNETCORE_URLS` | `http://127.0.0.1:5088` за HTTPS reverse proxy |
| `STARLIGHT_DATA` | абсолютный путь к приватному `users.json` |
| `STARLIGHT_RELEASES` | абсолютный путь к папке ZIP и `latest.json` |
| `STARLIGHT_MICROSOFT_CLIENT_ID` | собственный Application (client) ID |
| `STARLIGHT_CURSEFORGE_KEY` | ключ разработчика CurseForge |
| `STARLIGHT_NAT_PORT` | `5089`, UDP |

HTTPS proxy должен пропускать WebSocket для чата и relay. Для прямого соединения и голоса откройте UDP 5089. Локальный сервис на компьютере пользователя не создаёт публичный интернет-адрес.

Для выпуска на сервер используйте `-BaseUrl https://ваш-домен -Output путь-к-релизам`, перенесите ZIP и затем атомарно замените `latest.json`. В Docker каталог `deploy/releases` подключается только для чтения. Главная страница сервиса показывает ссылки на диагностику. `/api/client-config` не выдаёт секретный ключ CurseForge; каталог проксируется через ограниченные маршруты `/api/curseforge/...` с кешированием и лимитом запросов.

## Настройка Microsoft

Зарегистрируйте собственное приложение в Microsoft Entra с поддержкой личных Microsoft accounts; в Authentication включите **Allow public client flows**. Укажите полученный GUID в `STARLIGHT_MICROSOFT_CLIENT_ID`, перезапустите сервис и привяжите его в лаунчере. Client secret для desktop/device-code не нужен. Доступ Xbox/Minecraft должен быть разрешён для приложения; наличие одного GUID не гарантирует разрешение Minecraft Services. Нужен лицензированный Minecraft Java аккаунт с созданным профилем.

Официальные документы: [device code flow](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code), [ограничения логина по паролю](https://learn.microsoft.com/en-us/entra/msal/dotnet/acquiring-tokens/desktop-mobile/username-password-authentication). Парольный ROPC не поддерживает личные Microsoft accounts. Использовать чужой Client ID из Prism не требуется.

## Проверки выпуска

* Автоматические проверки: API retry, подписанные манифесты, импорт архивов, выход из каталога, symlinks, отмена и полный Microsoft/Xbox/Minecraft поток на имитации ответов.
* Реальный Modrinth: поиск, версии, скачивание и импорт полной сборки. Реальные Mojang и Fabric API.
* Локальный сервис: bootstrap, друзья, чат, P2P и резервный relay.
* `pwsh -File scripts/test-updater.ps1`: применение подписанного пакета, откат при занятом файле, отказ при повреждении и небезопасном пути.
* `pwsh -File scripts/test-update-feed.ps1`: получение подписанной ленты от настоящего локального сервиса, загрузка ZIP, подготовка и запуск автономного обновлятора на тестовой копии.
* Реальный Microsoft-вход и CurseForge с рабочими ключами требуют настройки владельца. На этой машине проверен Windows x64; другие платформы не запускались.

Протоколы каталогов изучены по официальной документации и структуре запросов Prism. Код Starlight не использует чужие OAuth идентификаторы или ключи API.
