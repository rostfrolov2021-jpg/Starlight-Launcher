ЕСТЬ ВОПРОС?

Отвечаем коротко.

Starlight бесплатный?+

Да, лаунчер бесплатный. Лицензия Minecraft приобретается отдельно.

Нужно скачивать установщик при каждом обновлении?+

Нет. В установленном Starlight открой «Обновления» и нажми «Обновить и перезапустить». Сборки и миры сохраняются.

На какой системе он работает?+

Для ПК — установщик Windows x64, для телефона — приложение Android (APK, arm64). Подключение к интернету нужно для загрузки игры, сборок и обновлений.

Можно подключаться к серверам?+

Да. Версия игры и моды должны подходить серверу. Серверы с проверкой лицензии требуют лицензионный аккаунт; offline-профиль его не заменяет. Вход Microsoft пока требует дополнительной настройки.
